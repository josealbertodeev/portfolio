## 👨‍💻 Sobre

Site estático, responsivo e sem frameworks, feito com HTML, CSS e JavaScript puro. Apresenta quem sou, minha trajetória, as tecnologias que uso e os projetos que construí.

## 🧭 Seções

- 🏠 **Início**: apresentação e links sociais
- 🙋 **Sobre**: quem sou
- 🕒 **Trajetória**: linha do tempo
- ⚡ **Skills**: tecnologias que domino
- 📁 **Projetos**: cards com link para o repositório e o deploy
- 📞 **Contato**: LinkedIn, WhatsApp, GitHub e e-mail
